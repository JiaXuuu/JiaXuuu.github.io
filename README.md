# Jelly Sliding developer website

Publish these files at the root of the `JiaXuuu.github.io` GitHub Pages repository.

- `https://jiaxuuu.github.io/` is the developer website.
- `https://jiaxuuu.github.io/app-ads.txt` is the AdMob authorized-seller file.
- The privacy policy remains at `https://jiaxuuu.github.io/jellyslide-privacy/`.

After publishing, set the App Store Connect Marketing URL to `https://jiaxuuu.github.io/`, then request an app-ads.txt recrawl in AdMob.
